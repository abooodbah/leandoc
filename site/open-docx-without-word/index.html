Open a .docx file without Word on Windows 11

Someone emails you a Word document and the PC has no Office. This page lists the ways to read it, what each one needs, and what each one cannot do. LeanDoc is one of them, and it is made by the author of this page.

Why Windows 11 has no built-in way

  • Windows 11 version 24H2 removed WordPad, which could open simple .docx files.
  • Microsoft retired the free Word Viewer in November 2017.
  • The Explorer preview pane shows .docx files only when Microsoft Office is installed.

The options, side by side

Pick by what you need to do: read the file, or change it.

Ways to open a .docx file without Microsoft Word
Option What it needs Can it edit?
Word for the web A Microsoft account and a browser. The file is uploaded first. Yes
LibreOffice Writer A free, open-source office suite to install. It also opens older .doc files. Yes
Explorer preview pane Microsoft Office installed on the PC. No
LeanDoc A small free install from the Microsoft Store, winget, Chocolatey, Scoop, or GitHub. Nothing is uploaded and no account is needed. No. It is read-only; one button hands the file to an editor.

Open a .docx with LeanDoc

  1. Install it from the Microsoft Store, or run winget install abooodbah.LeanDoc in a terminal.
  2. Open the file from LeanDoc, drop it on the window, or pick LeanDoc in Open With. It shows the document as pages.
  3. To change the document, press Open in .... It names Word, LibreOffice, or your default app for .docx, whichever LeanDoc finds first.

LeanDoc never runs macros and never fetches remote templates, linked images, or linked fields. It reads a cleaned copy of the document, not the original file.

Measured, not promised

LeanDoc 0.2.0 showed the first page of a 3-page document 377 ms after launch, and of a 300-page document 776 ms after launch: the median of six rounds of five launches on one GitHub-hosted Windows runner (AMD EPYC 9V45, WebView2 156), not a typical home PC.

The 0.2.0 Windows ZIP is 972,464 bytes, as GitHub lists the release file. LeanDoc draws pages with the Microsoft Edge WebView2 Runtime, which is not counted in that size.

Sources: the validation record and the 0.2.0 release page.

What LeanDoc does not do

  • It does not render older .doc files (Word 97 to 2003), .rtf, or .odt. They open to a page that says what the file is, with the button to your editor. Use Word or LibreOffice for those.
  • It does not display charts, SmartArt, or most text boxes. A bar above the page names what is missing and offers the editor.
  • It does not edit, save, or print.
  • Page breaks can fall in different places than in Word.
