# LeanDoc

**Read the document, not the office suite.**

LeanDoc is a focused, read-only desktop viewer for Word documents (`.docx`),
in development. It is a sibling of [LeanMark](https://github.com/abooodbah/leanmark)
and [LeanRows](https://github.com/abooodbah/leanrows).

There is no release yet. The plan and decisions are in [docs/SPEC.md](docs/SPEC.md),
[docs/EXECUTION_PLAN.md](docs/EXECUTION_PLAN.md), and [docs/adr/](docs/adr/README.md).
