# Fidelity score

Status for 0.1.0: **not yet scored.** No person has scored the list below
against Word yet, so LeanDoc publishes no fidelity figure for 0.1.0.

This file fixes what "renders a Word document well" means for LeanDoc, so
that a score from one release can be compared with the next. It follows
[SPEC section 7](SPEC.md#7-verification). The list and the rubric change only
in a pull request that says why, and a changed list starts a new series of
scores.

## How a release is scored

1. Build or download the release. Open each document below in LeanDoc in page
   view at 100 percent zoom, light theme.
2. Open the same document in Microsoft Word on the same machine. Word is the
   reference. If Word is not available, LibreOffice Writer may be used, and
   the score says so.
3. Score the five points of the rubric for that document, 1 or 0 each.
4. Record every score, the reference application and its version, the
   machine, the date, and a one-line note for every 0 in
   `docs/VALIDATION_STATUS.md`, under the release.

The release score is the sum over the 30 documents, out of 150. It is
published with the date, the reference application, and the number of
documents that scored 5.

## Rubric

Each point is 1 when it holds and 0 when it does not. A point that cannot
apply (a document with no table has no table to get wrong) scores 1 and is
marked `n/a`.

| Point | Scores 1 when |
| --- | --- |
| Text complete | Every paragraph, list item, table cell, header, footer, footnote, and endnote that Word shows is present, with no text missing, doubled, or garbled. Text inside content the fidelity bar names as not displayed (a text box, for example) counts as missing. |
| Order right | Paragraphs, lists, tables, and notes appear in Word's order, and right-to-left paragraphs and tables read in the right direction. |
| Styles right | Headings, emphasis, fonts (or close substitutes), sizes, colours, alignment, indentation, spacing, and list numbering match Word closely enough that a reader would not notice a different document. |
| Tables right | Every table has Word's rows and columns, merged cells, borders, and shading, and no cell content spills or is cut off. |
| Images right | Every picture Word shows is present, at about Word's size and position, and none is distorted. |

Pagination is not scored. LeanDoc breaks pages only where the document saved
a break (see the known gaps in the [0.1.0 release notes](releases/v0.1.0.md)),
so page counts can differ from Word's by design.
