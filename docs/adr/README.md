# Architecture decision records

These records define the constraints adopted by the LeanDoc implementation:

- [0001 - Rendering engine](0001-rendering-engine.md)

`Accepted` means that the decision governs the current implementation. It does
not turn an unrun benchmark into passing evidence. Runtime qualification lives
in [Acceptance](../ACCEPTANCE.md).

New decisions use the same context, decision, consequences, and validation
structure. An accepted decision is superseded by a new record rather than
silently rewritten.
