# LeanDoc v0.4.1

LeanDoc 0.4.1, a free Word (.docx) viewer for Windows, Linux and macOS, is a
patch release. Page view breaks pages much closer to where Word breaks them
in long, complex documents, and one more kind of damaged document now opens.
It adds no features.

## Release assets

| Platform | Artifact |
| --- | --- |
| Windows 10 and 11, x64 | **LeanDoc-v0.4.1-windows-x64.zip** |
| Ubuntu 24.04 and compatible, x86-64 | **LeanDoc-v0.4.1-linux-x86_64.deb** |
| macOS 12 or later, Intel and Apple silicon | **LeanDoc-v0.4.1-macos-universal-preview.zip** |

Every artifact has an adjacent **.sha256** sidecar. The macOS preview also has
a **.metadata.json** file that records how it was signed.

## Changed

- **Pages break closer to Word in long, complex documents.** A table row
  where Word started a page, or the line where Word split a row, now starts
  the page. A style takes only the styles it is based on, not the default
  paragraph style. A paragraph keeps with the next only when the document
  asks for it. Section breaks that are not continuous, and column breaks in
  a section of one column, start a page. Charts and SmartArt graphics keep
  their space as empty frames, and rows of exact height keep their height.
  Tabs, dot leaders, empty paragraphs, lines that hold only a picture, list
  labels, right-to-left text, HTML auto spacing and text in a missing
  Consolas take the space Word gives them.
- In a document of more than 60 pages, a page that holds the text of several
  pages is split after the first screen is shown, so the first screen
  appears as soon as before.

On a set of 38 public long documents opened in Word, 0.4.0 started 45.0
percent of pages where Word did on the 27 documents the changes were
tuned on, and 0.4.1 starts 69.1 percent. On the other 11 documents, held
out while tuning, it went from 43.9 to 48.9 percent. The method and every
step are in [the contest report](https://github.com/abooodbah/leandoc/blob/main/docs/parity-contest-2026-11.md).

## Fixed

- A document with a drawing whose graphic or picture data is missing now
  opens, without that drawing. Before, the whole document failed to
  display.

## Known gaps

- Two rules rest on comparisons with Word's pages, not on a measurement in
  Word: a paragraph with an outline level keeps its HTML auto spacing at the
  top of a later page, and the thresholds that decide when a long
  document's page is split.
- Documents whose tall pages are split take 0.15 to 0.45 seconds longer to
  have every page in place. The first screen is not slower.
- Many documents still break pages differently from Word, the held-out
  documents most of all.

## Speed and memory

The 1,000-page test report, 11 alternating runs of each version, medians:
it rendered in 1,697 ms against 1,693 ms for 0.4.0, with 392 MiB of memory
against 391 MiB.

## Installing

On Windows, run the installer from the extracted ZIP:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1 -OpenDefaultAppsSettings
```

## Signing and privacy

The Windows programs in the GitHub ZIP are not signed.

Privacy policy: This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.
LeanDoc's own code makes no network requests and never fetches anything a
document points to. The page is drawn by the system web runtime (the Microsoft Edge WebView2
Runtime on Windows, a Microsoft component), which may contact its vendor on
its own. The full policy, including how to uninstall, is in the
[README](https://github.com/abooodbah/leandoc#privacy-policy).
