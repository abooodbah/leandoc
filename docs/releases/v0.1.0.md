# LeanDoc v0.1.0

LeanDoc is a read-only desktop viewer for Word documents. It opens a `.docx`,
shows it as pages, never runs anything inside it, never fetches anything the
document points to, and has one button that hands the file to a real editor.

## Release assets

| Platform | Artifact |
| --- | --- |
| Windows 10 and 11, x64 | **LeanDoc-v0.1.0-windows-x64.zip** |
| Ubuntu 24.04 and compatible, x86-64 | **LeanDoc-v0.1.0-linux-x86_64.deb** |
| macOS 12 or later, Intel and Apple silicon | **LeanDoc-v0.1.0-macos-universal-preview.zip** |

Every artifact has an adjacent **.sha256** sidecar. The macOS preview also has
a **.metadata.json** file that records how it was signed.

## What it does

- Opens `.docx`, `.dotx`, `.docm`, and `.dotm` files. A portable C++ core
  reads the file within fixed size limits, checks the ZIP and the XML, and
  writes a new package with only allow-listed parts. The reader lays out that
  package with docx-preview. It never receives the original file.
- Shows page view by default, with a reading view one click away. Zoom runs
  from 50 to 300 percent, with fit width.
- Names what it does not display, and what it handled for you, in a quiet bar
  above the page: tracked changes are shown as accepted, comments are hidden,
  macros never run, and remote templates, images, and fields are never
  fetched.
- Offers a navigation pane from the headings, find, copy all text, and a
  System, Light, and Dark theme cycle. The page itself stays on paper colours.
- Shows a plain page for `.doc`, encrypted documents, `.rtf`, `.odt`, and
  files that are not Word documents, with the open-in-editor action.
- "Open in ..." uses Microsoft Word, then LibreOffice, then the system default
  app when it is not LeanDoc, then Word for the web in the browser. On macOS
  Pages is checked after LibreOffice. Word for the web cannot receive the file,
  so LeanDoc says it must be uploaded there.

## Platform notes

### Windows

The ZIP is portable. `installer/install.ps1` adds an optional per-user
install with Start menu, Open With, and Default Apps entries; it never changes
your default app for you. The executable is unsigned, so Windows may report an
unknown publisher or show a Microsoft Defender SmartScreen warning. The
Microsoft Edge WebView2 Runtime is required. Documents open as tabs in one
window, and a later launch hands its files to that window.

### Linux

The Debian package targets Ubuntu 24.04 and compatible x86-64 systems. The
package manager resolves GTK 4 and WebKitGTK 6.0. Documents open as tabs in
one window, and a later launch hands its files to that window.

### macOS preview

The ZIP holds a universal build for Intel and Apple silicon. It is ad-hoc
signed and not notarized by Apple, because the project has no Developer ID
credentials yet. Gatekeeper may ask for an explicit approval in **System
Settings > Privacy & Security**. The SHA-256 sidecar shows that the bytes match
this release; it does not prove who published them. Documents use the
system's window tabs.

## Known gaps

- Text boxes, equations, charts, and SmartArt are not displayed. The fidelity
  bar names them and offers the editor.
- `.doc` (Word 97 to 2003) files are not rendered. They get a fallback page.
- Pages break only where the document saved a page break or has an explicit
  break, so page numbers can differ from Word's.
- No printing.
- No comments panel. Comments are hidden and counted.
- Links in headers, footers, footnotes, and endnotes are plain text.
- The macOS build is a preview and is not notarized.
- Memory and start-up figures are not published yet. They will be, with the
  machine, method, and document named, once the owner's measurement run exists.
