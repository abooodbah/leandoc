# LeanDoc v0.3.3

LeanDoc 0.3.3, a free Word (.docx) viewer for Windows, Linux and macOS, is a
patch release with one fix. It adds no features.

## Release assets

| Platform | Artifact |
| --- | --- |
| Windows 10 and 11, x64 | **LeanDoc-v0.3.3-windows-x64.zip** |
| Ubuntu 24.04 and compatible, x86-64 | **LeanDoc-v0.3.3-linux-x86_64.deb** |
| macOS 12 or later, Intel and Apple silicon | **LeanDoc-v0.3.3-macos-universal-preview.zip** |

Every artifact has an adjacent **.sha256** sidecar. The macOS preview also has
a **.metadata.json** file that records how it was signed.

## Fixed

- **Nothing is cut off the bottom of a page when you zoom.** At zooms other
  than 100%, the last lines of a column or the last rows of a table could be
  hidden past the page's edge; in one test document rows 35 to 60 of a long
  table never showed at 90%. Such a page now grows a little taller so that
  all of its text shows. At 100% pages are laid out exactly as in 0.3.2.

## Known gaps

- A page that grows is taller than the paper. In the test document with the
  long table, page 1 is about 60 percent taller at 90%, because the table's
  rows wrap onto more lines at that zoom.
- The rest of the document is not laid out again at the new zoom, so page
  breaks stay where they were at 100%.

## Speed and memory

Headless runs on one Windows laptop, five alternating rounds, medians: the
3-, 60-, 300- and 1,000-page test reports opened within 1 percent of 0.3.2
with the same memory, and zooming and scrolling the 1,000-page report took
no longer.

## Installing

On Windows, run the installer from the extracted ZIP:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1 -OpenDefaultAppsSettings
```

## Signing and privacy

The Windows programs in the GitHub ZIP are not signed.

Privacy policy: This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.
LeanDoc's own code makes no network requests and never fetches anything a
document points to. The page is drawn by the system web runtime (the Microsoft Edge WebView2
Runtime on Windows, a Microsoft component), which may contact its vendor on
its own. The full policy, including how to uninstall, is in the
[README](https://github.com/abooodbah/leandoc#privacy-policy).
