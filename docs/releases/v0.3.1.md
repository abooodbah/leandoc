# LeanDoc v0.3.1

LeanDoc 0.3.1, a free Word (.docx) viewer for Windows, Linux and macOS, is a
patch release with one pagination fix. It adds no features.

## Release assets

| Platform | Artifact |
| --- | --- |
| Windows 10 and 11, x64 | **LeanDoc-v0.3.1-windows-x64.zip** |
| Ubuntu 24.04 and compatible, x86-64 | **LeanDoc-v0.3.1-linux-x86_64.deb** |
| macOS 12 or later, Intel and Apple silicon | **LeanDoc-v0.3.1-macos-universal-preview.zip** |

Every artifact has an adjacent **.sha256** sidecar. The macOS preview also has
a **.metadata.json** file that records how it was signed.

## Fixed

- **Fewer near-empty extra pages.** When a line or two runs past where Word
  started the next page, it now continues on that page, also across a
  section boundary.

## How close to Word

Measured on 57 real-world documents, with Word 16's page counts read through
COM:

| | 0.3.0 | 0.3.1 |
| --- | ---: | ---: |
| Same page count as Word | 34 of 57 | 39 of 57 |

49 of the 57 documents are laid out exactly as in 0.3.0. Opening times on six
test documents stayed within the run-to-run spread of 0.3.0.

## Known gaps

- A two-column document with a floating table, an anchored picture, or a
  dropped word wider than a column does not get this fix and keeps its
  near-empty page.
- Text that spans sections and fills more than a tenth of a page still gets
  a page of its own, where Word continues it.

## Installing

On Windows, run the installer from the extracted ZIP:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1 -OpenDefaultAppsSettings
```

## Signing and privacy

The Windows programs in the GitHub ZIP are not signed.

Privacy policy: This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.
LeanDoc's own code makes no network requests and never fetches anything a
document points to. The page is drawn by the system web runtime (the Microsoft Edge WebView2
Runtime on Windows, a Microsoft component), which may contact its vendor on
its own. The full policy, including how to uninstall, is in the
[README](https://github.com/abooodbah/leandoc#privacy-policy).
