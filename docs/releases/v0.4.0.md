# LeanDoc v0.4.0

LeanDoc 0.4.0, a free Word (.docx) viewer for Windows, Linux and macOS, adds
a Simplified Chinese and a Japanese interface and fixes three ways a document
could be shown wrongly or not at all.

## Release assets

| Platform | Artifact |
| --- | --- |
| Windows 10 and 11, x64 | **LeanDoc-v0.4.0-windows-x64.zip** |
| Ubuntu 24.04 and compatible, x86-64 | **LeanDoc-v0.4.0-linux-x86_64.deb** |
| macOS 12 or later, Intel and Apple silicon | **LeanDoc-v0.4.0-macos-universal-preview.zip** |

Every artifact has an adjacent **.sha256** sidecar. The macOS preview also has
a **.metadata.json** file that records how it was signed.

## Added

- **Simplified Chinese and Japanese interface.** LeanDoc follows the system
  language: Japanese on a Japanese system, Simplified Chinese on a
  Simplified Chinese system, and English on every other, Traditional Chinese
  included. Settings has a new Language choice (System, English, 简体中文,
  日本語) that is saved with the other settings. The toolbar, settings panel,
  shortcut list, notes about content LeanDoc does not display, status
  messages, file dialogs, Windows error messages and the macOS menus all
  follow it. Documents are shown as they were written.

## Fixed

- **Documents with pictures stored in a compatibility block open.** Some
  files saved by older Mac versions of Word keep a picture's image inside a
  compatibility block. Such a document failed to display at all; it now
  opens with its pictures.
- **A kept paragraph taller than a page is split across pages.** A paragraph
  set to keep its lines together that is taller than a whole page stayed on
  one oversized page. It is now split at a line boundary once it starts at
  the top of a page, as Word does. In a test document, a 40-line paragraph
  on a short page now fills three pages instead of one.
- **Nonbreaking hyphens show.** A Word nonbreaking hyphen was dropped, so a
  hyphenated word lost its hyphen and could break across two lines with no
  mark. It now shows as a hyphen and keeps the word together.

## Known gaps

- There is no Traditional Chinese interface. Traditional Chinese systems
  keep English and can choose 简体中文 in Settings.
- The Japanese and Chinese text has not been reviewed by a native speaker.
- The Linux command-line usage text and start-up errors printed to the
  terminal stay in English, and the right-click menu drawn by the web
  runtime follows the system language, not the chosen one.
- In two-column layouts, where an oversized kept paragraph is split can
  still differ from Word.

## Speed and memory

Measured on the pull requests that made these changes, each against the
code before it, in the reader test harness on one Linux machine rather
than in the installed app. With the interface change, rendering the
1,000-page test report took 39 ms (2 percent) longer at the median, inside
the range of the earlier code's own runs. With that report open, the test
browser's processes used 389.5 MiB (median of 6 runs) with the English
interface and 396.0 MiB with the Japanese one, against 388.5 MiB before.
The paragraph and hyphen fixes left the timing and memory of the same
report unchanged within run-to-run noise.

## Installing

On Windows, run the installer from the extracted ZIP:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1 -OpenDefaultAppsSettings
```

## Signing and privacy

The Windows programs in the GitHub ZIP are not signed.

Privacy policy: This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.
LeanDoc's own code makes no network requests and never fetches anything a
document points to. The page is drawn by the system web runtime (the Microsoft Edge WebView2
Runtime on Windows, a Microsoft component), which may contact its vendor on
its own. The full policy, including how to uninstall, is in the
[README](https://github.com/abooodbah/leandoc#privacy-policy).
