# LeanDoc v0.1.1

LeanDoc 0.1.1 lays out documents that carry no page breaks into pages. In
0.1.0 such a document showed as a single page as tall as all of its text.

## Release assets

| Platform | Artifact |
| --- | --- |
| Windows 10 and 11, x64 | **LeanDoc-v0.1.1-windows-x64.zip** |
| Ubuntu 24.04 and compatible, x86-64 | **LeanDoc-v0.1.1-linux-x86_64.deb** |
| macOS 12 or later, Intel and Apple silicon | **LeanDoc-v0.1.1-macos-universal-preview.zip** |

Every artifact has an adjacent **.sha256** sidecar. The macOS preview also has
a **.metadata.json** file that records how it was signed.

## Fix

- **Pages for documents without page breaks.** LeanDoc's renderer starts a
  page only where the document marks one: a manual page break, a section
  break, or the page markers Word saves when it lays a document out. Files
  written by python-docx, pandoc, and other generators have none of these, so
  a whole paper appeared as one page. Page view now measures each page against
  its own height and bottom margin and moves what does not fit to a new page
  with the same size, margins, header, and footer. Tables split between rows,
  a heading stays with the text that follows it, and notes go to the last page.

On a 938-paragraph research paper with no page markers, 0.1.0 showed one page
19,000 pixels tall; 0.1.1 shows 42 pages, each exactly the page height.

## Known gaps

- A paragraph is moved to the next page whole rather than split between lines,
  so a long paragraph can leave space at the bottom of the page before it. No
  text is lost and no page overflows. Word splits such a paragraph by lines.
- Documents of more than 60 pages that already carry page markers are shown as
  before; the new layout applies to documents of up to 60 marked pages, which
  covers every unmarked document.
- The header on pages added by the new layout repeats the page's own header; a
  different first-page header is not swapped for the default one.

## Installing

On Windows, run the installer from the extracted ZIP:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1 -OpenDefaultAppsSettings
```

Installing over 0.1.0 keeps your settings and file associations.
